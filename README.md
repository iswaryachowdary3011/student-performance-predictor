# 🎓 Student Performance Predictor

A beginner-friendly machine learning project that predicts a student's academic performance based on study habits and academic factors.

## 📌 About the Project

The Student Performance Predictor uses a Decision Tree machine learning model to predict a student's performance level.

The prediction is based on:

- Study hours per day
- Attendance percentage
- Previous marks
- Assignment score

The project also includes a simple Streamlit web interface where users can enter student details and receive a prediction.

## 🚀 Features

- Predicts student performance
- Simple and interactive Streamlit interface
- Uses a Decision Tree machine learning model
- Takes multiple academic factors as input
- Easy to run locally

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
